Guide 02

Language tour

Lume favors explicit data and control flow without requiring ceremony around ordinary application code. This tour explains the stable mental model; the full syntax reference remains authoritative.

Bindings and mutation

A bare assignment introduces an immutable binding. Add a type when it improves the contract or supplies context for inference. Mutable bindings use var, while reassignment uses :=.

name = "Ada"
count Int = 1
var retries = 3
retries := retries - 1

Local bindings cannot silently shadow parameters, fields, or another live local. Field access can be qualified with this when a parameter has the same name.

Classes, shapes, enums, and objects

A class is nominal: construction and class-to-class assignment depend on its declared identity. A shape is structural data with public immutable fields. An enum describes tagged alternatives, and a named object declares one shared object value.

shape Location {
    city Str
    country Str
}

class User {
    name Str
    location Location
}

enum Access {
    Admin
    Member { organization Str }
}

object Defaults {
    country Str = "US"
}

Interfaces describe behavior. Classes, shapes, enums, annotations, and named objects can explicitly implement interfaces; enum cases cannot.

Construction

Class constructors are declared with new(...). Braces supply construction fields by name, while parentheses supply explicitly positional constructor inputs in declaration order.

impl User {
    new(name Str, location Location) = {
        this.name = name
        this.location = location
    }
}

ada = User {
    name: "Ada"
    location: Location("London", "UK")
}

Anonymous shapes use the same named field form without a type name:

summary = {
    name: ada.name
    active: true
}

Pattern matching and destructuring

let supports irrefutable destructuring directly. Refutable bindings require an else path. if let branches on a pattern, and match handles alternatives exhaustively.

let { name, location } = ada

let Some(first) = users.get(0) else return

label = match access {
    case Admin => "administrator"
    case Member { organization } => organization
}

Tuple, list, shape, class, and enum patterns are name-aware where the source data is named. List patterns may capture a remainder with spread syntax.

Option, Result, Either, and try

Lume represents optional values and recoverable failure explicitly. try unwraps the success side and propagates the container's failure. Use mapError or mapLeft before try when the enclosing function uses a different error type.

load(id Int) Result[User, AppError] = {
    row = try Db.queryRow("select ...", id)
        .mapError(error => AppError.Db(error))

    Ok(decodeUser(row))
}

The lifted access operator .-> accesses one member inside Option, Result, or Either. Each hop maps a plain result or flat-maps the same container family.

Lists and maps

Collection types and literals use parallel bracket syntax. Empty collections stay self-describing.

names [Str] = ["Ada", "Grace"]
scores [Str : Int] = ["Ada": 10, "Grace": 12]

emptyNames [Str] = []
emptyScores [Str : Int] = []

Higher-order methods accept explicit lambdas or compatible function and bound-method references. A lambda uses => and may use a block body.

lengths = names.map(name => name.size())
labels = names.map(name => {
    upper = name.upper()
    "$upper!"
})

Java source generation and interoperability

The frontend completes parsing, resolution, and type checking before Java source is generated. Java-specific class loading and descriptors live at the backend boundary, allowing the core compiler model to remain Lume-oriented.

cargo run --manifest-path rust/Cargo.toml -p lume -- \
    gen app/main.lum --out build/generated/lume

Lume libraries can wrap Java dependencies behind Lume interfaces. The repository includes database, JSON, HTTP, Gradle, and Java compatibility examples.
